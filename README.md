# Edit OSX

A native macOS app that runs Microsoft's [`edit`](https://github.com/microsoft/edit) terminal editor in its own window, so you can open and edit text files from Finder without ever launching a terminal.

## What it is for

`edit` is a small, friendly terminal editor in the spirit of the classic MS-DOS Editor: menus along the top, VS Code–style shortcuts, mouse support. It is great, but it lives in a terminal. Edit OSX gives it a proper Mac home:

- Double-click or "Open With" a file in Finder and it opens in `edit`.
- Each file gets its own window, with standard Mac window, menu and full-screen behavior.
- Choose from 10 readable color schemes, and resize the font with ⌘+ / ⌘−.

It is a good fit if you want a quick, lightweight text editor for config files, notes and source code, and you like `edit`'s interface.

## How it works

Edit OSX does not reimplement an editor. It is a thin Swift/AppKit shell:

1. Each window hosts an embedded terminal emulator ([SwiftTerm](https://github.com/migueldeicaza/SwiftTerm)).
2. The terminal launches the real `edit` binary with the file you opened, as `xterm-256color` with truecolor.
3. When `edit` exits (for example, you close the file), the window closes. When the last window closes, the app quits.

Because it is just a wrapper, **`edit` must be installed separately.** Edit OSX looks for it in `~/.cargo/bin`, `~/.local/bin`, `~/bin`, `/opt/homebrew/bin`, `/usr/local/bin`, `/opt/local/bin`, and then your `PATH`. If it can't find `edit`, it asks you to choose its location, and remembers your choice.

## Download and install (no building required)

Requirements: a Mac with Apple silicon (arm64) running macOS 13 or later.

1. **Install `edit`.** Download a binary from [microsoft/edit releases](https://github.com/microsoft/edit/releases/latest), or see the [`edit` README](https://github.com/microsoft/edit#installation) for package-manager options, and put the `edit` binary in one of the folders above.
2. **Download the app.** Go to this repo's [Releases page](../../releases/latest) and download `Edit-OSX-<version>.zip`.
3. **Install.** Unzip it and drag **Edit OSX.app** into your **Applications** folder.
4. **Open it the first time.** The app is ad-hoc signed but not notarized by Apple, so macOS will warn about it. Do one of:
   - Right-click (or Control-click) **Edit OSX.app** → **Open** → **Open**, or
   - Run in Terminal: `xattr -cr "/Applications/Edit OSX.app"`

You only need to do step 4 once.

## Using it

- **Open a file:** double-click a text or source file in Finder, choose **Open With → Edit OSX**, or use **File → Open…** (⌘O) in the app.
- **New window:** **File → New Window** (⌘N) starts `edit` with no file (it opens its own scratchpad).
- **Edit as usual:** everything inside the window is `edit`. Use its own menus (File, Edit, View, Help) and shortcuts, such as Ctrl+S to save and Ctrl+Q to quit the file.
- **Copy and paste:** ⌘C and ⌘V work with the system clipboard.
- **Font size:** **View → Increase / Decrease Font Size** (⌘+ / ⌘−), **Actual Size** (⌘0).
- **Full screen:** **View → Enter Full Screen** (⌃⌘F).
- **Color scheme:** **View → Color Scheme (New Windows)**. Your choice is saved. It applies to windows you open afterwards, because `edit` reads its colors only when it starts.
- **Point to a different `edit`:** **Edit OSX → Choose edit Executable…** (⌘,). You can also set the `EDIT_OSX_EDIT_PATH` environment variable.

### Color schemes

Vivid (default), Dracula, Nord, Gruvbox Dark, Solarized Dark, Solarized Light, Tokyo Night, Catppuccin Mocha, Rosé Pine and Kanagawa Wave.

Each scheme's background and text colors are tuned for contrast: text against the background is at least 10:1, and text against the current-line highlight bar is at least 7.5:1.

## Building from source

Only needed if you want to change the app. Requires Xcode or the Command Line Tools with Swift 5.9+.

```sh
./build.sh
```

This produces `build/Edit OSX.app`. To install it, copy the app to `/Applications`. The app icon is generated by `swift scripts/make-icon.swift`.

## Layout

| Path | Purpose |
| --- | --- |
| `Sources/EditWrapper/AppDelegate.swift` | App lifecycle, menus, opening files |
| `Sources/EditWrapper/TerminalWindowController.swift` | One window: terminal view and the `edit` process |
| `Sources/EditWrapper/EditLocator.swift` | Finds, or asks for, the `edit` executable |
| `Sources/EditWrapper/Theme.swift` | The 10 color schemes |
| `Resources/` | `Info.plist` and the app icon |
| `build.sh` | Builds and ad-hoc signs the app bundle |
